# Local configuration

Test readiness, restart and upgrades before using real material. HTTP request
bodies are limited to 65 MiB. The manual upload form accepts files up to 25 MiB;
autonomous onboarding accepts files up to 64 MiB. The API's file reader limits
individual uploads to 64 MiB.

Run from the repository root. Settings load from environment variables and root
`.env`; environment takes precedence. Setup creates database and Weaviate
credentials with file mode 0600.

| Variable | Purpose | Local default |
| --- | --- | --- |
| `NEWTON_DATABASE_URL` | SQLAlchemy PostgreSQL URL | Generated by setup |
| `NEWTON_POSTGRES_PASSWORD` | Initial Compose PostgreSQL password | Generated |
| `NEWTON_WEAVIATE_API_KEY` | Private Weaviate service credential | Generated |
| `NEWTON_WEAVIATE_HOST` | Weaviate host | `127.0.0.1` |
| `NEWTON_WEAVIATE_HTTP_PORT` | Weaviate REST port | `18080` |
| `NEWTON_WEAVIATE_GRPC_PORT` | Weaviate gRPC port | `15051` |
| `NEWTON_VISUAL_ENCODER_URL` | Private loopback ColQwen service or SSH forward | Unset |
| `NEWTON_DATA_DIR` | Private original files | `.runtime/data` |
| `NEWTON_BUDGET_PATH` | API admission ledger | `.runtime/budget.json` |
| `NEWTON_COOKIE_SECURE` | HTTPS-only cookie flag | `false` for loopback HTTP |
| `OPENAI_API_KEY` | OpenAI answers and text embeddings | Unset |
| `GEMINI_API_KEY` | Gemini answers | Unset |

Provider keys come from the process environment. Keep them out of `.env`, example
files, checked-in commands, browser code and research output. The provider selector
reports configuration status; a request verifies access.

## API spending

Setup initializes a zero budget. While the app is stopped, set the ledger's
`ceiling` to the spend you authorize and keep existing `paid_attempts`.

```json
{"currency": "EUR", "ceiling": 0, "paid_attempts": []}
```

Each external request reserves an amount under a file lock before sending. Reported
usage settles the reservation; ambiguous failures retain it. Rates in
`server/newton/budget.py` expire and need source-backed updates before new requests.
Newton does not retry failed paid requests or raise the cap.

## Storage and deployment

PostgreSQL owns accounts, companies, metadata, mappings, conversations and run
state. Originals remain private files under `NEWTON_DATA_DIR`; Weaviate is derived.
Back up the database and originals together. Compose volumes preserve data across
`docker compose stop`; deleting volumes or `.runtime/data` deletes evidence.

Loopback is the supported deployment boundary. Shared deployments need HTTPS,
secure cookies, host and origin controls, login abuse protection, account recovery,
shared company roles, isolated document parsing, migrations and restore testing.

## Private visual encoder

The optional encoder uses a pinned ColQwen checkpoint on a loopback Apple Silicon
host or through a verified SSH forward. Set
`NEWTON_VISUAL_ENCODER_URL=http://127.0.0.1:18766` before starting Newton.
Answering indexes at most 32 PDF/image pages per machine, selects up to three by
ColQwen MaxSim, and sends bounded page images to the selected model. Retrieval
scores do not measure confidence, image relevance or diagnostic truth.
